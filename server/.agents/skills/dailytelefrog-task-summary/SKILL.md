# Итоговая сводка и название чата по задаче

Этот скилл формирует единообразное название вкладки чата и краткую сводку, чтобы пользователь мог удобно сохранить историю сессии и быстро вернуться к контексту задачи.

## Когда вызывать

- Автоматически сразу после пуша завершённой задачи в `main` (или в конце задачи, если пользователь завершает работу в чате без пуша через агента).
- По явному запросу пользователя («как назвать вкладку/чат», «дай сводку по задаче»).

## Формат вывода

Всегда выводи ответ строго в такой структуре:

1. **Название вкладки чата** — в отдельном code-блоке (для копирования в один клик) в формате `#<номер задачи> <краткое описание в 4–7 слов>`, например:

```text
#0041 Отвязка тестов от Docker-путей и healthcheck MySQL
```

Если задача не привязана к конкретному номеру из `issues/`, вместо `#<номер>` укажи короткую метку области (`#DOCS`, `#INFRA`, `#HOTFIX` и т.п.).

2. **Краткая сводка по задаче:**
   - **Задача и коммит:** номер и ссылка на файл в `issues/done/` (или `issues/`), ветка, хеш коммита в `main` (если уже закоммичено/запушено).
   - **Что сделано:** 2–4 коротких пункта по затронутым файлам и изменениям.
   - **Ключевые решения:** важные развилки или причины нетривиальных деталей (1–2 пункта; если не было — можно опустить).
   - **Тесты:** итог прогона unit- и e2e-тестов (количество пройденных и время, если запускались).
